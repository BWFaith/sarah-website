SARAH DUSCHKA WEBSITE
=====================
Open index.html (or upload the whole folder to your host).

CHANGE IMAGES: replace files in /images using the SAME file names (any placeholder says "REPLACE THIS IMAGE").
  images/sarah/profile.jpg       About page + agent card (use a larger, high-resolution photo)
  images/sarah/activity-*.jpg    Recent activity flyers
  images/listings/<id>-1..4.jpg  Listing photos (4 per property)
  images/banners/*.jpg           Page header photos
  images/home/*.jpg              Home page photos

CHANGE LISTINGS: edit js/data.js (all listings are SAMPLES). Contact details are at the top of that file.

EMAILS: searches and forms are emailed to the address in js/data.js through FormSubmit.co.
  1) The site must be hosted online (forms do not send when opened from a local file).
  2) The first submission sends an activation email to that inbox. Click "Activate" once, then all emails arrive.
